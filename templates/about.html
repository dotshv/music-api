About

A small REST API for searching songs and streaming audio, made for bots and apps.

What it is

{{ site_name }} gives developers search, lookup and audio streaming over plain HTTP. Telegram and Discord bots, web apps and scripts can use it without an account or an API key.

How it works

Search results come from public music catalogs. When you request a stream, the audio is found on demand and passed through to you. Nothing is stored on the server except short-lived cached search results.

Fair use

Requests are limited per IP address{% if rate_limit %} ({{ rate_limit }} per minute){% endif %} so everyone gets a fast API. Please cache results where you can and don't resell access to the API. See the rate limit docs for details.

Independent project

{{ site_name }} is built and maintained independently. It isn't affiliated with, endorsed by or sponsored by Spotify or any record label. All music, names and artwork belong to their respective owners.
