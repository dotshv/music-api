Getting started

Send a request, get JSON back. CORS is enabled, so you can also call the API from a browser.

Base URL

{{ base_url }}/api/v1

First request

curl "{{ base_url }}/api/v1/songs?query=kesariya&limit=1"

Not sure what to send? Try it in the playground.

Search songs

Search the catalog by song title or artist name.

GET /songs

Query parameters

NameDescription
queryRequired. Song title or artist, up to 120 characters.
limitOptional. Number of results, 1 to 25. Default 10.

Response

{
  "status": "success",
  "query": "kesariya",
  "count": 1,
  "results": [ /* song objects */ ]
}

Get a song

Title and cover art for a Spotify track ID or link.

GET /songs/{id}

Response

{
  "status": "success",
  "data": { /* song object */ }
}

Stream audio

Returns the audio itself. Use the stream_url from any song object as the source of an audio element, or give it to your bot's voice player.

GET /songs/{id}/stream

Query parameters

NameDescription
sourceOptional. spotify, saavn or itunes. Already set in every stream_url.
qOptional. Title and artist, used to find audio when no direct source exists. Already included in every stream_url.

The content type depends on the source, for example audio/ogg, audio/webm or audio/mp4. Streams aren't cached.

Resolve a link

Turns a Spotify track link, a Spotify URI or a plain song title into one song. Handy when a user pastes or types something and you want a single result.

GET /resolve

Query parameters

NameDescription
queryRequired. A song title, or a Spotify track link or URI.

Example

curl "{{ base_url }}/api/v1/resolve?query=https://open.spotify.com/track/4cOdK2wGLETKBW3PvgPWqT"

{
  "status": "success",
  "song": { /* song object */ }
}

Song object

Every endpoint that returns a song uses this shape.

FieldDescription
idTrack ID. Use it in /songs/{id}.
titleSong title.
artistArtist names, comma separated. May be empty.
albumAlbum name. May be empty.
thumbnailCover art URL. May be empty.
duration_secLength in seconds, or null if unknown.
sourceWhere the result came from: Spotify or Catalog.
stream_urlReady-to-use audio URL.
spotify_urlLink to the track (or a search) on Spotify.

Errors

Errors use the same JSON body and a matching HTTP status.

{
  "status": "error",
  "code": 404,
  "message": "Track not found"
}
StatusMeaning
400Unknown source value.
404No track matched.
422A parameter is missing or out of range. The message names it.
429Rate limit reached. See Retry-After.
500The audio stream couldn't be started. Try again or pick another track.

Every response carries an X-Request-ID header. Include it when you report a problem.
